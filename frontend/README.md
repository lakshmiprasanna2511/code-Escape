# CodeEscape — Frontend

React + Vite client for CodeEscape. See the root `README.md` (one level up) for
full-stack setup instructions (backend + MongoDB Atlas required for auth, game
state, leaderboard, and multiplayer rooms to work).

```bash
cp .env.example .env   # point at your backend, defaults to http://localhost:5000/api
npm install
npm run dev
```
