🚀 Code Escape

An interactive multiplayer escape room game where players solve coding, aptitude, and English questions to compete and escape faster than others.

🌐 Live Demo

👉 Play here: https://code-escape-oa6o.vercel.app/

🧠 Project Idea

Code Escape is a unique twist on traditional escape room games.
Instead of physical puzzles, players solve:

💻 Coding questions
🧩 Aptitude problems
📖 English challenges

Players can create rooms, invite friends, and compete in real-time.

✨ Features
👥 Multiplayer room creation
🏆 Real-time competition
⏱️ Timer-based challenges
🧠 Multiple question categories
🔐 Room-based gameplay
🌐 Deployed and accessible online
🛠️ Tech Stack
Frontend: HTML, CSS, JavaScript
Backend: (Replit backend / Node.js if used)
Deployment: Vercel
Version Control: GitHub
